SMT FORMAL PROOF: UNSAT (BITWISE EQUIVALENT)

Baseline (-O3 -march=x86-64-v3 -flto)

; Скалярный разбор по 1 байту с каскадом прыжков
.L_parse_loop:
    movzx   eax, byte ptr [rsi]
    cmp     al, 0x0a            ; Проверка на LF
    je      .L_matched_lf       ; Промах предсказателя переходов
    cmp     al, 0x0d            ; Проверка на CR
    je      .L_matched_cr
    inc     rsi
    dec     rcx
    jnz     .L_parse_loop       ; Высокая задержка конвейера

LLM Super-Opt (AVX2 / AVX-512 + tzcnt)

; Векторный разбор по 32 байта за такт без ветвлений
.L_simd_avx2:
    vmovdqu ymm0, ymmword ptr [rsi] ; Загрузка 32 байт
    vpcmpeqb ymm1, ymm0, ymm2       ; Сравнение параллельно
    vpmovmskb eax, ymm1             ; Преобразование в 32-бит маску
    tzcnt   ebx, eax                ; Поиск первого бита за 1 такт
    add     rsi, rbx
    sub     rcx, rbx
    ; Результат: 0 branch mispredictions, 2.45x ускорение

Слайд 1. Хук и Экономика

20 000 ядер прокси в k8s: высвобождаем 2 500–3 000 процессорных ядер простой заменой бинарника в Docker-образе.

Слайд 2. Почему не PGO / BOLT?

BOLT меняет только layout блоков для кэша. Наша модель переписывает сам внутренний алгоритм на AVX-512 и убирает ветвления.
